# 그림 노트

그림을 처음 시작하거나 꾸준히 연습하고 싶은 사람이 오늘 그릴 대상과 시간을 정하는 페이지입니다. 계획을 입력하고 내용을 확인한 뒤 완료 화면을 보면 계획 준비가 끝납니다.

시작 → 입력 → 확인 → 완료의 네 단계로 구성했습니다. 연습 계획 시작 버튼의 click 이벤트가 발생하면 입력 화면으로 이동합니다. 대상과 시간을 입력하며, 메모와 이메일은 적지 않아도 됩니다.

계획 확인하기를 누르면 submit 이벤트로 입력값을 검사합니다. 대상이 비어 있거나 시간을 고르지 않으면 수정할 내용을 안내하고 입력 단계에 머무릅니다. 이메일을 적었다면 형식도 확인합니다. 검사를 통과하면 대상, 시간, 메모, 이메일을 보여 주고 확인 단계로 이동합니다. 계획 준비 완료 버튼의 click 이벤트에서는 계획을 확인한 상태인지 검사하고, 완료 안내와 최종 계획을 보여 줍니다.

이전으로 돌아가면 입력한 값이 남습니다. 값을 고치고 다시 확인하면 바뀐 내용이 나옵니다. 완료 화면에서도 확인 단계로 돌아갈 수 있습니다. 다시 쓰기는 입력란을 비웁니다. 다시 시작 버튼의 click 이벤트는 입력값과 선택, 오류, 확인 결과, 진행 상태를 초기화하고 시작 단계로 돌아가도록 연결했습니다.

연습 팁은 관찰, 선, 색의 세 탭으로 나눴습니다. 메모를 입력하면 글자 수가 바뀌고, 시간을 고르면 그에 맞는 안내가 나옵니다. 화면이 768px 이하이면 메뉴와 카드, 입력창과 버튼을 세로로 배치했습니다.

1100px, 768px, 390px에서 시작부터 완료까지 진행해 봤습니다. 필수값 누락과 이메일 오류에서는 다음 단계로 넘어가지 않았습니다. 이전 단계의 값 유지와 수정 반영, 다시 시작할 때 초기화되는 것도 확인했습니다. 탭과 글자 수, 시간 안내가 작동했고 긴 내용을 넣어도 잘림이나 가로 스크롤은 없었습니다.

입력한 내용은 현재 화면에서만 유지되고 새로고침하면 지워집니다. 이메일을 실제로 보내지는 않습니다.
