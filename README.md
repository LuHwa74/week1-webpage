# 그림 노트

그림 연습 전에 그릴 대상과 연습 시간을 적어 두는 페이지입니다. 무엇부터 그릴지 고민하는 사람이 계획을 정하고 나중에 다시 볼 수 있게 만들었습니다.

7주차에는 계획을 입력하고 확인한 뒤 완료하는 과정까지 만들었습니다. 이번에는 완료한 계획을 목록에 보관하고 다시 여는 기능을 추가했습니다. 새로고침해도 보관한 내용이 남도록 했습니다.

계획 작성을 끝내고 보관 버튼을 누르면 목록에 추가됩니다. 같은 내용이 있으면 중복 안내가 나오고 추가되지 않습니다. 보관한 계획은 다시 열어 볼 수 있고, 필요 없으면 목록에서 뺄 수 있습니다. 마지막으로 뺀 계획은 되돌릴 수 있습니다. 목록이 비면 새 계획을 작성할 수 있도록 안내가 나옵니다.

대상과 시간은 꼭 입력해야 합니다. 빠진 값이나 잘못된 이메일이 있으면 고칠 내용을 알려 줍니다. 이전으로 돌아가도 입력값은 남고, 수정한 값은 확인 화면에 반영됩니다. 다시 시작하면 작성 중인 내용과 진행 상태가 초기화됩니다.

보관한 내용은 이 브라우저의 localStorage에 남습니다. 저장에 실패하거나 다른 탭에서 목록을 바꾸면 안내가 나옵니다. 설정을 확인하거나 목록을 다시 불러온 뒤 시도하면 됩니다. 이메일을 실제로 보내지는 않습니다.

계획 두 개를 보관하고 새로고침한 뒤 다시 열어 내용이 남는 것을 확인했습니다. 중복 보관, 필수값 누락, 이전 단계에서 수정, 목록 비우기, 빼기와 되돌리기도 확인했습니다. 저장 실패와 다른 탭의 변경에서는 기존 목록을 덮어쓰지 않았습니다.

1100px, 768px, 390px와 배포 페이지에서 조작해 봤고 화면 잘림이나 가로 스크롤은 없었습니다. PC와 모바일에서 보관, 다시 열기, 빼기, 되돌리기가 정상적으로 되는지 확인했습니다.
